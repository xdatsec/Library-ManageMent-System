# CHMSU Library Management System

A web-based **Library Management System (LMS)** developed as a college project for **Carlos Hilado Memorial State University (CHMSU)**.

> **Note:** This is an old college project that I recently revisited and started refactoring. Some parts of the code are poorly structured, outdated, or could be written much better today — **but it works.** **
>

---

## Features

### ** Library Management

- Book management
- Book acquisition
- Book inventory
- Library members
- Alumni records
- Thesis management
- Book borrowing
- Book returning
- Borrowed and returned records
- Collection status

### ** User Management

- Librarian/Admin accounts
- User management
- User list
- Password management
- Authentication
- Activity logs

### ** Bulletin Board

- Create announcements
- Display announcements
- Delete announcements
- Admin-controlled bulletin board

### ** Library Attendance

- Library card number login
- Attendance/session tracking
- One-hour library attendance session

### ** Reports

The system includes various printable and previewable reports:

- Book reports
- Accession reports
- Inventory reports
- Collection reports
- Borrowed/returned reports
- Thesis reports
- Entrance reports
- Other library-related reports

Reports can be previewed, opened in a new window, and printed.
